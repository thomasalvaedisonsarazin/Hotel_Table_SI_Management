DineOps SI Camera

Video stays on this computer and is never saved. Only the number of people at each table is sent to DineOps SI. Tell people if they're being filmed.

1. Connect

Create one in the app under Settings for the restaurant you're using. Demo restaurants won't ring phones, so use a real one.

With the IP Webcam app on Android, press Start server and add /video to the address it shows. The phone and this computer must be on the same Wi-Fi. Enter 0 to use this computer's own camera.

2. Mark your tables

The camera picture appears here once it's connected.

Choose a table, then drag across the picture to cover the table and its chairs. Green boxes are guests, orange boxes are staff.

    3. Start

    The camera can't otherwise tell a waiter from a guest. A bright apron lets it notice that a waiter has reached the table.
